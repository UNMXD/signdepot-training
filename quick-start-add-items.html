Done. That line is on the estimate. Add the next thing they are buying the same way, then build each line out in the next section.

Quick sheet: the line item standard

The name is: how many, the size, SS or DS, what it is, then extras after a slash. Two sizes of the same product join in one name with AND.

A decal named by its words: the wording goes first, one line per wording. A vehicle job: the vehicle goes first, with no number in front. Service and fee lines, like DESIGN or INSTALLATION, get no number in front either.

The Customer Description is ALL CAPS and never repeats the name. Only what the customer should see goes in it, or leave it blank. File status uses the standard phrases, like LOGO PROVIDED BY CUSTOMER.

Inside the line, the material, sides, laminate, grommets, and machine must match what the name promises. Every line gets a category. Design or install is charged once, never in both places.

Keep customer names and instructions out of the name. Instructions live in the Notes tabs, section 5.
