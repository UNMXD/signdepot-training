Sales Quick Start Guide

Creating an order or estimate, step by step.

← Back to Sales

Small chunks, in the order you actually do it: start it, add the items, build each line, add the Notes, use the Chat, and check it before you save. An order starts the same way as an estimate, with + New Order. This is the short version; each chunk links to the full standard behind it. To learn EVO in general, EVO has its own Training track inside the program (Account menu, My Profile, Onboarding).

1. Start It and Add the Items

Watch the video first. Then do the steps.

0 steps

Done. The estimate is started and open. Now add what they are buying.

That is everything the Details step asks. There is no due date, Pickup, terms, or tax box here: the terms and the 8.25% tax ride along on the estimate by themselves, and delivery or install legs live in the estimate's Destinations tab.

Now add the items. Watch the video first. Every thing they buy gets its own line.
