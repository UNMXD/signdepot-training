Finding Print Files

Print only from 03_Print_Ready in the order's Drive folder (SD-ACCOUNTS). The suffix tells you the file: _PRINT prints, _CUT cuts. If it is not in 03_Print_Ready, do not print it. SD-Active is archive only.
