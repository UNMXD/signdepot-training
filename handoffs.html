The Slack Channels

EVO is where the job lives. Slack is where the job gets talked through. The EVO order number is the key in every post, so anyone can find the job in EVO fast.

#sd-design-needed

Where artwork gets requested and approved. Post the order number first, then the customer and product, the size and specs, when it is needed, and the client file or proof attached.

The real work happens in the thread: file quality, sizes, colors, client answers. Proofs must state the colors (CMYK, RGB, or spot), so production prints what the proof shows.

The stage ends with a clear instruction: proof approved, prepare the file for printing, update the status to production.

#sd-production

The ready-to-print queue. One short line: the order number, the customer, "ready to print", and the EVO link to the order.

Threads carry the follow-up: rush and ETA chases, vendor status, material questions, pickup-only exceptions.

#sd-completed

The record that it got done. Post the customer name, the order number, "install / complete", and on-site photos as proof, and tag Yida to close the loop.

Almost no discussion here. It is proof, not chat.
